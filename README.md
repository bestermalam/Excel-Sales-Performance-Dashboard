# Excel Sales Performance Dashboard

## Project Overview

Developed an interactive **Sales Performance Dashboard** using Microsoft Excel to analyze sales revenue, product performance, transactions, and business trends. The project demonstrates practical skills in data preparation, cleaning, analysis, reporting, and visualization.

## Dashboard Features

- Four charts showing sales by City, Category, Product, and Salesperson.
- Four interactive slicers for dynamic filtering.
- PivotTable-based KPI calculations and reporting.
- Automatic updates of charts and KPIs when slicers are selected.

## Excel Skills Demonstrated

- **Data Entry & Excel Tables:** Organizing structured sales records.
- **Data Cleaning:** Identifying blank values and correcting data ranges.
- **Sorting & Filtering:** Organizing and filtering sales data.
- **Excel Formulas:** SUM, AVERAGE, COUNT, and COUNTA.
- **PivotTables & PivotCharts:** Summarizing and visualizing sales performance.
- **Interactive Slicers:** Filtering charts and KPIs by Product, Category, City, and Salesperson.
- **KPI Analysis:** Calculating revenue, transactions, quantities, and sales statistics.
- **Dashboard Design:** Building professional, interactive business reports.

## How to Use

1. Download `Sales_Performance_Dashboard.xlsx`.
2. Open the workbook in Microsoft Excel.
3. Select the **Dashboard** worksheet.
4. Use the slicers to explore sales performance.

## Project Purpose

Developed as a practical data analysis project to demonstrate Microsoft Excel skills in data preparation, cleaning, sorting, filtering, formulas, PivotTables, PivotCharts, interactive reporting, and dashboard development for **Data Analyst internship and entry-level opportunities**.
